# 6. Репетиція вголос

**Мета:** сказати власну відповідь без читання повного тексту.

**Логіка:** підтримка поступово зменшується: спершу видно власний текст, потім — короткі смислові опори. Учень сам позначає, що справді спробував.

**Екран:** питання, власний матеріал і кілька зрозумілих опор. Англійську підказку можна відкрити за потреби; таймер необов’язковий.

**Не додавати:** таймер як вимогу, оцінювання за самим натисканням кнопки чи приховану перевірку усної спроби.

**Можна змінювати:** опори, коротке уточнювальне питання, тривалість орієнтира й спосіб позначити власну спробу.
