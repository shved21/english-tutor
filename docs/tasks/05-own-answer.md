# 5. Моя відповідь

**Мета:** зібрати власне пояснення з попередніх чернеток.

**Логіка:** учень редагує вже написані речення, додає особисті деталі та готує текст для говоріння. Не переписує все з нуля.

**Екран:** власні речення, короткі локальні опори та дія для збирання відповіді. Показуємо саме текст учня.

**Не додавати:** зайві письмові завдання перед усною практикою або нові факти про учня, яких він не вводив.

**Можна змінювати:** порядок речень, питання для персоналізації, початки фраз, словник і вигляд зібраного тексту.
