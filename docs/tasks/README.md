# Правила задач

Ці файли пояснюють призначення й межі кожної вправи людською мовою. Це місце, де можна запропонувати, що змінити в логіці або на екрані. Загальні правила вигляду зібрані у [`DESIGN.md`](../../DESIGN.md), порядок кроків — у [`LESSON_FLOW.md`](../../LESSON_FLOW.md).

| Крок | Файл | Що можна змінювати |
|---|---|---|
| 1. Контекст і текст | [01-context-and-text.md](01-context-and-text.md) | Тему, подачу, довжину й допоміжні матеріали. |
| 2. Чотири речення | [02-four-sentences.md](02-four-sentences.md) | Кількість, інструкцію, приклади, підказки й перевірку. |
| 3. Вибір фраз | [03-phrase-selection.md](03-phrase-selection.md) | Добір, пояснення та спосіб вибору фраз. |
| 4. Діалог із фразами | [04-phrase-dialogue.md](04-phrase-dialogue.md) | Репліки, формат відповіді й обсяг допомоги. |
| 5. Моя відповідь | [05-own-answer.md](05-own-answer.md) | Як збираються чернетки й персоналізується відповідь. |
| 6. Репетиція вголос | [06-speaking-rehearsal.md](06-speaking-rehearsal.md) | Опори, темп і момент показу англійських підказок. |
| 7. Розмова у Voice | [07-voice-conversation.md](07-voice-conversation.md) | Поведінку співрозмовника й формат підсумку. |
| 8. Підсумок | [08-summary.md](08-summary.md) | Поля запису й те, що переноситься на наступний урок. |

У кожному описі є дві окремі частини: **логіка** — навіщо потрібна вправа; **екран** — що учень бачить і робить. Побажання можна писати простою мовою. Після зміни правил реалізацію в застосунку теж треба оновити.
