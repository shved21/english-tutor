# 8. Підсумок

**Мета:** зберегти, що справді сталося, і вибрати корисну правку для наступного уроку.

**Логіка:** наступний урок спирається на реальні відповіді, помилки й відгук, а не на перегляд сторінок чи згенерований план.

**Екран:** короткі поля для результату розмови та необов’язкового відгуку; одна зрозуміла дія збереження або експорту.

**Не додавати:** дублювання вже збереженої відповіді, оцінку без реального бала чи текст «немає запису», якщо він нічого не допомагає вирішити.

**Можна змінювати:** поля підсумку, спосіб експорту й формат нотатки для наступного уроку. Чітко відрізняти реальний результат від навчального прикладу.
