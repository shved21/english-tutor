# English Tutor

**[Відкрити English Tutor](https://shved21.github.io/english-tutor/)**

English Tutor — персональна програма на 50 навчальних днів для практичної англійської в робочих розмовах, IT-співбесідах і власних проєктах. Кожен урок веде від теми дня через читання та побудову речень до власної відповіді й усної практики.

## Як тут усе влаштовано

- [Логіка уроку](LESSON_FLOW.md) — навіщо потрібні вісім кроків і як вони пов’язані.
- [Правила дизайну](DESIGN.md) — що має бути на сторінках і як впливати на їхній вигляд.
- [Карта файлів проєкту](docs/PROJECT_MAP.md) — де реалізовані сторінки, стилі, дані й перевірки.

## Запустити на комп’ютері

Потрібен Python 3. У корені проєкту виконай:

```bash
python3 -m http.server 8766
```

Потім відкрий <http://127.0.0.1:8766/>.

Примітка: логіка уроку та правила дизайну тут описують задум, але ще не є джерелом, з якого GitHub автоматично збирає сторінки. Пов’язання цих правил із кодом описане в [карті проєкту](docs/PROJECT_MAP.md).
