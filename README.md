# English Tutor

**[Відкрити English Tutor](https://shved21.github.io/english-tutor/)**

Персональний тренажер англійської для практики читання, письма й розмови.

## Як тут усе влаштовано

- [Логіка уроку](LESSON_FLOW.md) — навіщо потрібні вісім кроків і як вони пов’язані.
- [Правила дизайну](DESIGN.md) — що має бути на сторінках і як впливати на їхній вигляд.
- [Опис кожної задачі](docs/tasks/README.md) — окремі правила й побажання для восьми вправ.
- [Карта файлів проєкту](docs/PROJECT_MAP.md) — де реалізовані сторінки, стилі, дані й перевірки.

## Запустити на комп’ютері

Потрібен Python 3. У корені проєкту виконай:

```bash
python3 -m http.server 8766
```

Потім відкрий <http://127.0.0.1:8766/>.

Правила описують бажану поведінку й дизайн. Щоб побачити зміни в застосунку, відповідні файли коду теж мають бути оновлені.
