# Тренажери уроків

Ця папка містить опубліковані сторінки тренажерів і архів минулих уроків. Зараз тут дві окремі реалізації:

- `index.html`, `app.js`, `styles.css` — рання версія повного тренажера, яку програма відкриває для Дня 14.
- `day30/` — зібрана сторінка поточного уроку Дня 30: `index.html` і `today.js` містять матеріал, а інші JS/CSS забезпечують роботу й вигляд.
- `archive/` — матеріали минулих уроків для читання.

Кореневий `app.js` пов’язує картки програми з цими сторінками. Поточний урок Дня 30 було зібрано з локального джерела правил, але сам збирач і його джерела поки не входять до цього GitHub-репозиторію. Через це зміна контракту локально не оновлює опубліковану сторінку автоматично.

План структури: спільні правила й контракти задач → шаблони та стилі → одна команда збірки → папка зібраної сторінки. Старі уроки лишаються в архіві; особистий журнал і відповіді учня — поза публічним репозиторієм. Детальніше — у [карті проєкту](../docs/PROJECT_MAP.md).
